# Portfolio background and project previews

## What will change
- Upgrade the existing fixed background into a continuous, subtle field of glowing network lines and particles behind the full page.
- Keep the effect non-interactive, low contrast, and lightweight; reduce or stop movement when the visitor prefers reduced motion.
- Create six cohesive preview images matching each existing project: crypto explorer, social dashboard, task manager, weather app, portfolio, and game website.
- Add one preview image to each existing project card while preserving its title, description, tags, controls, and layout.
- Leave the working contact form and its email delivery unchanged.

## Technical details
- Use a fixed decorative layer with CSS transforms and opacity-only animation for smooth performance.
- Use responsive image sizing, lazy loading, explicit dimensions, and subtle card-image interaction.
- Verify the page at desktop and mobile sizes, including scrolling, card rendering, click access, and browser errors.
